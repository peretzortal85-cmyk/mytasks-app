המשימות שלי — גרסת PWA להתקנה באנדרואיד

1. העלי את כל הקבצים בתיקייה זו יחד לאחסון HTTPS כגון GitHub Pages או Cloudflare Pages.
2. פתחי בטלפון את כתובת האתר באמצעות Chrome.
3. בתפריט שלוש הנקודות בחרי "התקנת אפליקציה" או "הוספה למסך הבית".
4. המערכת שומרת את המשימות מקומית במכשיר בלבד. אין עדיין סנכרון בין מכשירים.
5. בצעי גיבוי JSON תקופתי. לפני החלפת גרסה, גבי ושחזרי נתונים במידת הצורך.
6. פתיחת index.html ישירות מהמכשיר לא תאפשר התקנת PWA; צריך HTTPS (או localhost לצורכי פיתוח).

העיצוב והפעולות מבוססים על גרסה 4 שאישרת.
